# Robot Learning Tutorial Beamer Decks

This folder contains the maintained Beamer slide suite for the robot learning tutorial.

The decks are derived from the tutorial source in this repository and reuse the visual language of the older ICLR Beamer template.

## Structure

- `shared/`: common Beamer theme, macros, and typography
- `01-introduction/`
- `02-classical-robotics/`
- `03-reinforcement-learning/`
- `04-imitation-learning/`
- `05-generalist-robot-policies/`

Each chapter deck compiles independently and is maintained manually as a derivative of the tutorial chapters.

## Notes

- Figures and logos are referenced from the local tutorial repository.
- The decks reuse the same visual language as the ICLR Beamer template, but the content is rewritten for the tutorial chapters.
